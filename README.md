# 영상 채널 성과 분석 (2019–2021)

> 직접 운영한 엔터테인먼트 팬 콘텐츠 채널의 YouTube Studio 데이터를 **노출 → 클릭 → 시청 → 전환** 퍼널로 사후 분석한 개인 프로젝트입니다.
> 유료 광고 집행 경험이 아니며, 운영이 끝난 채널의 데이터를 2026년에 분석했습니다.

**결과 페이지:** `https://<github-id>.github.io/<repo-name>/` · **분석 노트북:** [`analysis.ipynb`](analysis.ipynb)

## 한눈에 보기

|---:|---:|---:|---:|---:|
| 287만 | 3.42% | 12.4만 | 5,750시간 | +218 |

분석 기간: 2019-01-13 ~ 2021-12-31 (채널 누적 조회수의 95.5%)

## 주요 발견

1. **채널은 두 개의 엔진으로 움직였다.** 급증 2주(2019.3.9–22) 조회수의 97%는 추천·탐색, 나머지 34개월 조회수의 83%는 검색에서 발생했다. *(사실)*
2. **급증은 삭제된 영상에서 발생했다.** 급증 당시 존재한 현존 영상(L1)의 조회수는 평소 수준이었다 *(사실)*. 채널 합계에서 차감해 구한 삭제 영상 지표가 채널의 추천 유입 지표와 거의 일치한다(평균 시청 2:43 vs 2:45, 조회율 59.9% vs 57.6%)는 점에서, 급증 영상은 삭제가 확인된 4분 32초 영상일 가능성이 높다. *(추정)*
3. **경로 간 조회율 차이는 경로의 특성이 아니다.** 역산한 평균 영상 길이가 추천 약 5분, 검색 약 23분으로, 경로별로 소비된 영상 유형 자체가 달랐다. *(사실)*
4. **KPI 선택에 따라 평가가 뒤집힌다.** 조회율로는 짧은 클립(63–79%)이, 평균 시청 시간으로는 롱폼(210–273초)이 우수하다. *(사실)*
5. **집계 단위가 전환 해석을 바꾼다.** 1,000회당 구독 순증가가 채널 일별 기준으로는 급증 기간이 12배 높지만, 영상별 기준으로는 1.3배 차이에 그친다. *(사실)*

## 데이터와 방법

- YouTube Studio 고급 모드 CSV: 영상별 요약, 유입 경로별 요약, 유입 경로별 일별 조회수, 채널 일별 조회수·구독자
- 영상은 제목·ID 대신 유형 코드(L1, S1 …)로 익명화하며, 원본 CSV는 공개하지 않습니다.
- 비공개 이력이 있는 영상은 일별 데이터로 비공개 시점을 확인하고, 모든 영상이 공개 상태였던 기간으로 분석을 한정했습니다.
- 표기: **사실**(데이터로 확인) / **추정**(근거는 있으나 직접 확인 불가) / **가설**(검증되지 않은 해석)

## 한계

- 영상 수가 적어 통계 검정은 하지 않았습니다. 모든 결론은 사례 관찰입니다.
- 삭제 영상 지표는 채널 합계에서 현존 영상을 뺀 값이고(확인된 삭제 영상 외 다른 삭제 영상 존재 여부 미확인), 비공개 이력 영상 3개는 비공개 시점을 확인하지 못했습니다.
- 영상별 유입 경로 데이터를 확보하지 않아 경로 분석은 채널 단위로만 해석했습니다.

## 구성

```
index.html                 결과 페이지 (GitHub Pages)
analysis.ipynb             전체 분석 과정
data/processed/            익명화된 분석 결과 CSV
data/raw/                  원본 CSV (비공개, .gitignore)
```

노트북을 다시 실행하려면 YouTube Studio에서 받은 원본 CSV를 `data/raw/`에 노트북의 파일명대로 넣어주세요.

**사용 기술:** Python · pandas · Jupyter · HTML/SVG

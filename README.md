# 조회수의 57.2%가 집중된 14일, 유입 경로는 어떻게 달랐을까?

> 직접 운영했던 영상 채널의 2019–2021년 YouTube Studio 데이터로 **채널 합계와 영상별 합계의 정합성을 점검하고, 일별 추이·유입 경로·KPI별 성과 차이를 분석해 매체 운영·리포팅 시사점**을 정리한 사후 분석 프로젝트입니다. 유료 광고 집행 경험이 아닙니다.

- **결과 페이지:** https://bomin7740-afk.github.io/yt-channel-analysis/
- **공개 분석 노트북:** [analysis.ipynb](https://github.com/bomin7740-afk/yt-channel-analysis/blob/main/analysis.ipynb) — `data/processed/`만으로 실행됩니다.

## 수행 역할

2019–21 채널 운영(콘텐츠 기획·편집·게시), 분석 목적과 질문 설정, YouTube Studio 데이터 추출, 결과 검토와 해석·수정 판단.
코드 작성 방식은 아래 [작업 방식](#작업-방식)에 적었습니다.

## 한눈에 보기 (채널 합계, 2019-01-13 ~ 2021-12-31)

| 썸네일 노출수 | 썸네일 클릭률(CTR) | 조회수 | 총 시청 시간 | 구독 순증가 |
|---:|---:|---:|---:|---:|
| 2,868,407 | 3.42% | 123,577 | 5,749.6시간 | +218 |

조회수는 모두 YouTube Studio의 **유효 조회수** 기준입니다. 분석 기간 조회수는 전체 기간(~2026-10-31) 유효 조회수 129,374회의 95.5%입니다.

## 주요 결과

1. **조회수의 58.6%는 현존 영상 목록 밖에 있었다.** 현존 9개 영상의 조회수 합계는 51,168회로 채널 합계의 41.4%입니다. 조회수·시청 시간·노출수의 차이는 현존 목록에서 확인되지 않는 성과(잔여분)로 봤고, 집계 범위가 다른 구독(+141명 차이)은 어떤 영상에도 귀속하지 않았습니다. *(사실)*
2. **조회수의 57.2%가 집중된 14일, 나머지 기간의 주요 유입 경로는 검색이었다.** 2019년 3월 9–22일 일별 조회수는 386–14,278회로 직전 4주 일평균(75회)의 약 5–189배였습니다. 이 14일 조회수의 96.9%는 추천·탐색에서, 나머지 기간 조회수의 83.4%는 검색에서 발생했습니다. *(사실, 관측된 구성비이며 인과관계가 아님)* 급증 조회수의 99.3%(70,128/70,636회)가 현존 목록 밖에서 발생했으며, 이는 전체 잔여분의 96.8%(70,128/72,409회)입니다. *(계산)* 확인된 삭제 영상이 기여했을 가능성은 있지만, 특정 영상의 기여 규모와 삭제 시점·개수·원인은 확인하지 못했습니다. *(추정)*
3. **검색은 CTR이 높았지만 평균 시청 지속 시간의 차이는 작았다.** 검색 CTR(15.39%)은 추천(1.84%)의 약 8.4배였고, 평균 시청 지속 시간은 검색 2분 23초·추천 2분 45초로 22초 차이였습니다. 영상 길이·콘텐츠 구성 차이를 분리하지 못해 경로 자체의 우열로 해석하지 않았습니다.
4. **KPI에 따라 영상 평가가 달라졌다.** 짧은 영상은 평균 조회율(26–79%)에서, 롱폼 음성 콘텐츠는 평균 시청 지속 시간(약 210–270초, 공개용 반올림 값)에서 높았고, 롱폼 3개가 채널 시청 시간의 38.4%를 차지했습니다. *(사실)* 사례 수가 적어 유형의 효과를 입증한 것은 아닙니다.

## 데이터와 재현 방법

```
비공개 원본 data/raw/ (공개하지 않음)
   └─ scripts/build_public_data.py   원본이 있어야 실행되는 전처리
        └─ data/processed/*.csv       공개용 CSV
             └─ analysis.ipynb        공개 분석 노트북 — 이 파일들만으로 실행
```

| 공개 CSV | 내용 | 수준 |
|---|---|---|
| `channel_totals.csv` | 채널 합계, 전체 기간 유효·일반 조회수 | 채널 단위 원본 값 |
| `channel_daily_views_2019_2021.csv` | 채널 일별 유효 조회수 | 채널 단위 원본 값 |
| `traffic_sources_2019_2021.csv` | 유입 경로별 노출·CTR·조회수·평균 조회율 | 채널 단위 원본 값 |
| `traffic_by_period_source.csv` | 급증 14일 / 나머지 기간 × 유입 경로별 조회수 | 채널 단위 원본 값 |
| `monthly_views_by_source.csv` | 월별 유입 경로 그룹별 조회수 | 채널 단위 원본 값 |
| `subscribers_daily_2019_2021.csv` | 채널 일별 구독 순증가 | 채널 단위 원본 값 |
| `aggregation_check.csv` | 채널 합계 vs 현존 영상 합계 | 원본 합계 |
| `exact_aggregates.csv` | 영상별 원본에서만 구할 수 있는 집계값(L1 급증 기간 조회수, 롱폼 시청 시간 합계 등) | 결과값만 제공, 재계산 불가 |
| `videos_2019_2021_public.csv` | 영상별 공개 값 | 연도·길이 구간·반올림 |

**공개용 반올림 값과 원본의 차이:** 영상별 값은 게시 연도, 길이 구간, 노출수 100·조회수 10·평균 시청 지속 시간 10초 단위, 평균 조회율 정수, 시청 시간 정수로 공개합니다. 현존 9개 영상의 공개값 합계와 원본 합계의 차이는 0.05% 이내입니다(노트북 6절). 결과 페이지의 채널 합계와 비율은 원본 값, 영상별 표·차트·범위는 공개용 값입니다.

## 작업 방식

분석 목적과 질문 설정, 데이터 추출, 결과 검토와 해석·수정 판단은 직접 했습니다. 전처리 스크립트, 분석 노트북(Python, pandas, matplotlib), 결과 페이지의 초기 코드는 AI(Claude)가 작성했으며, AI(ChatGPT)의 교차 검토와 코드·문서 수정을 거쳤습니다.

## 한계

- 영상 수가 적어 통계 검정은 하지 않았습니다. 모든 결론은 사례 관찰입니다.
- 잔여분은 현존 영상 목록이 완전하다는 전제의 계산값이며, 목록에서 확인되지 않는 콘텐츠의 개수·삭제 날짜·사유는 기록이 없습니다.
- 영상별 유입 경로, 신규·취소 구독, 구독 발생 위치 자료가 없어 경로별 시청 품질과 구독 기여도는 판단하지 않았습니다.
- 공개 노트북으로 결과 페이지의 계산은 재현할 수 있지만, 영상별 원본 집계값은 재계산할 수 없고 공개 데이터가 원본과 일치하는지는 독립적으로 검증할 수 없습니다.

## 실행과 파일 교체

저장소 루트에서 다음을 실행합니다(Python 3.10 이상).

```bash
python -m pip install -r requirements.txt
jupyter notebook analysis.ipynb
```

한글 차트에는 NanumGothic, Noto Sans CJK KR, 맑은 고딕 등 한글 폰트가 필요합니다. 제공된 노트북에는 실행 결과가 포함돼 있습니다.

이번 수정은 HTML뿐 아니라 노트북·README·CSV 설명·전처리 코드에도 적용됐습니다. GitHub에는 ZIP 내부 `yt-analysis/`의 내용을 기존 저장소 루트에 덮어씁니다. 폴더 자체를 한 단계 더 중첩하지 않습니다. 비공개 원본은 업로드하지 않습니다. `index.html`만 교체하면 웹 본문은 바뀌지만 노트북과 데이터 설명은 이전 상태로 남습니다.

## 해석 시 주의

- 3월 22일 14,278회에서 **3월 23일 46회**로 급감했습니다. 급감일과 삭제일을 동일시하지 않습니다.
- L1은 급증기 일평균 36.3회, 직전 4주 47.9회로 채널 전체와 같은 급증이 없었습니다.
- 비공개 전환 이력은 운영자 기록이며 정확한 전환일은 미확인입니다. `*_last_view_month`는 마지막 조회 발생 월이며 비공개 전환 월이 아닙니다.
- 급증 외 기간은 관측된 비교 구간입니다. 정상적인 기준 성과를 추정한 결과가 아닙니다.
- 본 분석은 자연 유입 사례입니다. 캠페인 KPI는 후속 적용 계획이며 광고 효율 개선의 실증 결과가 아닙니다.

# 영상 채널 성과 분석 (2019–2021)

> 2019–2021년 직접 기획·편집·운영한 엔터테인먼트 팬 콘텐츠 채널의 YouTube Studio 데이터를 2026년에 사후 분석한 개인 프로젝트입니다. 채널 합계와 영상별 합계를 대조해 집계 범위를 점검하고, 일별·월별 추이와 유입 경로를 나눠 성과가 어디서 나왔는지 확인했습니다.
> 유료 광고 집행 경험이 아닙니다.

**결과 페이지:** `https://<github-id>.github.io/<repo-name>/` · **분석 노트북:** [`analysis.ipynb`](analysis.ipynb)

분석 기간 조회수는 전체 기간(~2026-10-31) 조회수 129,374회의 95.5%입니다.

## 주요 결과

1. **조회수의 58.6%는 현존 영상 목록 밖에 있었다.** 현존 9개 영상의 조회수 합계는 51,168회로 채널 합계의 41.4%입니다. 조회수·시청 시간·노출수의 차이는 현존 목록에서 확인되지 않는 성과(잔여분)로 봤고, 집계 범위가 다른 구독(+141명 차이)은 귀속하지 않았습니다. *(사실)*
2. **조회수의 57.2%가 몰린 14일, 나머지 기간은 검색이 지탱했다.** 2019년 3월 9–22일 조회수의 96.9%는 추천·탐색, 나머지 기간 조회수의 83.4%는 검색에서 발생했습니다. *(사실)* 급증 조회수의 대부분은 현존 목록 밖에서 발생했고(잔여분의 96.8%), 운영자 기록상 저작권 문제로 삭제된 영상일 가능성이 높습니다. *(추정)*
3. **경로 간 지표 차이를 경로의 우열로 읽지 않았다.** 추천과 검색은 노출 규모·CTR·평균 조회율이 크게 달랐지만, 영상 길이·콘텐츠 구성 차이를 분리할 자료가 없어 경로 자체의 시청 품질은 판단하지 않았습니다.
4. **KPI에 따라 영상 평가가 달라졌다.** 짧은 영상은 평균 조회율(26–79%)에서, 롱폼 음성 콘텐츠는 평균 시청 시간(210–273초)에서 높았고, 롱폼 3개가 채널 시청 시간의 38.4%를 차지했습니다. *(사실)* 사례 수가 적어 유형의 효과를 입증한 것은 아닙니다.

## 데이터와 방법

- YouTube Studio 고급 모드 CSV(2026-11-02 추출): 영상별 요약, 유입 경로별 요약·일별 조회수, 채널 일별 조회수·구독 순증가, 상위 5개 영상 일별 조회수
- 영상은 제목·ID 대신 유형 코드(L1, S1 …)로 익명화하며, 원본 CSV는 공개하지 않습니다.
- 표기: **사실**(원본 관측값 또는 그 합·차·비율) / **참고**(가정을 둔 계산값) / **추정** / **가설**
- CTR 해석은 노출 5,000회 이상 영상만, 시청 성과 비교는 조회 30회인 P1만 제외했습니다(분석자가 정한 탐색 기준).

## 한계

- 영상 수가 적어 통계 검정은 하지 않았습니다. 모든 결론은 사례 관찰입니다.
- 잔여분은 현존 영상 목록이 완전하다는 전제의 계산값이며, 삭제 콘텐츠의 개수·삭제 날짜는 기록이 없습니다.
- 영상별 유입 경로, 신규·취소 구독, 구독 발생 위치 자료가 없어 경로별 시청 품질과 구독 기여도는 판단하지 않았습니다.
- 비공개 시점은 3개 영상만 일별 데이터로 추정했고, 공개 상태의 영향은 확인 가능한 범위에서만 줄였습니다.
- 영상마다 게시 시점이 달라, 누적값은 분석 기간의 채널 성과 기여도입니다.

## 구성

```
index.html                 결과 페이지 (GitHub Pages)
analysis.ipynb             분석 과정 (사이트 수치의 산출 과정, 분자·분모 포함)
data/processed/            익명화된 분석 결과 CSV
data/raw/                  원본 CSV (비공개, .gitignore)
```

원본 CSV가 비공개라 공개 저장소만으로는 노트북을 재실행할 수 없습니다. 결과는 노트북 출력과 `data/processed/`로 확인할 수 있습니다.

**사용 기술:** Python · pandas · Jupyter · HTML/SVG
